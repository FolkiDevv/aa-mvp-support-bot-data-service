# AGENTS.md — data-service агента Support Bot

Правила для ИИ-агентов (любых) и людей. `CLAUDE.md` ссылается сюда.

## Что это

- `services/support-bot-data` — Litestar-сервис рядом с БД агента.
  Единственный путь к данным агента для админ-панели. Работает **только
  по mTLS** (без сертификатов не стартует).
- `services/support-bot-data-client` — типизированный клиент
  (pydantic-DTO + httpx с mTLS). Его использует модуль админки; публикуется
  в приватный индекс вместе с сервисом (одна версия).
- `deploy/certs/generate.sh` — dev-сертификаты; в проде сертификаты выдаёт
  команда агента (см. `deploy/certs/README.md`).

Шаблон содержит пример (промпты + аналитика диалогов) — замени его
операциями своего агента. Скилл: `.agents/skills/create-data-service`.

## Правила

1. Набор операций определяет команда агента, но каждая операция:
   эндпоинт в сервисе + метод клиента + DTO в `models.py` клиента +
   строка в docstring-таблице API + контрактный тест
   (`tests/test_contract.py`: настоящий клиент против `TestClient`).
2. Сервис и клиент не импортируют друг друга и ничего из админки
   (`import-linter`).
3. Только чтение, кроме явно нужных админке операций записи.
   Тяжёлую аналитику — на реплику БД.
4. Без `# noqa`/`# type: ignore` без кода и причины; не ослаблять конфиги.

## Команды

```bash
uv sync --all-packages
make check            # ruff + WPS + mypy strict + import-linter + pytest (cov ≥ 90%)
deploy/certs/generate.sh
```
